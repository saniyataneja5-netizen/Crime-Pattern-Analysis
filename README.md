# Crime Pattern Analysis and Prediction Using Machine Learning

## Overview
This project analyzes urban crime data using Machine Learning techniques to identify crime patterns, detect hotspots, classify crime categories, and forecast future crime trends. The system combines supervised learning, clustering algorithms, and time-series forecasting to provide actionable insights from crime datasets.

## Features
- Crime domain classification using Machine Learning models
- Crime hotspot identification and clustering
- Exploratory Data Analysis (EDA)
- Crime trend visualization
- Monthly crime forecasting
- Interactive visualizations using Plotly and Folium

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
- Plotly
- Folium
- Statsmodels

## Machine Learning Models
### Classification
- Logistic Regression
- Support Vector Machine (SVM)
- Decision Tree
- Random Forest
- Gradient Boosting

### Clustering
- K-Means Clustering
- DBSCAN

### Forecasting
- ARIMA
- SARIMA

## Dataset
The project uses an Indian urban crime dataset containing over 40,000 crime records with features such as:
- Crime Type
- City
- Crime Domain
- Victim Information
- Weapon Used
- Police Deployment
- Case Status
- Date and Time Information

## Workflow
1. Data Collection and Preprocessing
2. Exploratory Data Analysis
3. Feature Engineering
4. Crime Classification
5. Crime Clustering
6. Time-Series Forecasting
7. Visualization and Dashboard Generation

## Results
- Achieved effective crime classification using Logistic Regression and SVM models.
- Identified meaningful crime clusters using K-Means.
- Forecasted future crime trends using SARIMA models.
- Generated hotspot visualizations for better crime analysis.

## Team Project
This project was developed as part of a semester academic project at MIT Manipal.
